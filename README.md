# 📋 Registro de Cadastro em Java

Este projeto é um sistema simples de **registro de cadastro** desenvolvido com o objetivo de **praticar e aprimorar minhas habilidades em Java**, com foco especial no uso da estrutura de dados **HashMap**.

## 🎯 Objetivo

O principal intuito deste projeto foi:

- 💡 Explorar e entender melhor o funcionamento do `HashMap`, uma das estruturas de dados mais utilizadas em Java.
- 👨‍💻 Consolidar conhecimentos em manipulação de dados, lógica de programação e boas práticas na linguagem.
- 🚀 Dar mais um passo rumo ao desenvolvimento de sistemas mais robustos e dinâmicos.

## 🛠️ Tecnologias e Conceitos Utilizados

- **Java**
- **HashMap**
- Entrada e saída de dados via terminal
- Estruturas condicionais e laços de repetição
- Organização e modularização de código

## 🧠 Aprendizados

Durante o desenvolvimento deste sistema, tive a oportunidade de:

- Entender a importância de mapas na associação de dados (chave-valor).
- Implementar uma lógica clara e funcional para cadastro de usuários ou informações.
- Praticar a interação com o usuário via terminal de forma fluida.
